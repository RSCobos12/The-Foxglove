# The Foxglove
# Homepage Style Guide v1.0

_Last Updated: July 2026_

---

# Purpose

This document defines the visual, interactive, and philosophical standards of The Foxglove website.

Every future page should inherit these standards to ensure a cohesive and premium user experience.

When making future design decisions, consistency is valued over novelty.

---

# Brand Identity

The Foxglove represents:

- Tradition
- Prestige
- Brotherhood
- Competition
- Sophistication
- Restraint

The experience should feel like an invitation into a private golf society rather than a commercial sports website.

---

# Design Philosophy

Less, but better.

Every element should have a purpose.

When deciding between two designs:

**Choose the quieter one.**

Luxury rarely announces itself.

---

# Color Palette

## Primary Navy

The primary canvas of the website.

Used throughout the homepage to create depth and elegance.

---

## Gold

Reserved for emphasis.

Used for:

- Dividers
- Icons
- Borders
- Hover accents
- Crest
- Seal

Gold should never dominate the page.

---

## Cream

Primary reading color.

Used instead of pure white to create warmth.

---

# Typography

## Headlines

Elegant serif typography.

Centered whenever appropriate.

Large.

Confident.

Generous spacing.

---

## Body Copy

Readable before decorative.

Short paragraphs.

Comfortable line spacing.

Editorial feel.

---

## Navigation

Minimal.

Balanced around the crest.

Never oversized.

Navigation should never distract from the hero.

---

# Hero Section

Purpose:

Establish atmosphere before information.

Current behavior:

- Hero image displays immediately.
- Hero image remains visible for 2 seconds.
- Hero video fades in over 2.8 seconds.
- Video plays once.
- Hero image returns.
- Hero image remains for 15 seconds.
- Cycle repeats.

The hero should feel cinematic rather than promotional.

---

# Welcome Section

Purpose:

Introduce the spirit of The Foxglove.

Emotion before logistics.

Botanical illustrations:

- Decorative only.
- Opacity: 0.08
- Frame the body copy.
- Never compete with typography.

---

# Cards

Purpose:

Invite exploration.

Standards:

- Equal height
- Equal spacing
- Gold foxglove icon
- Minimal hover animation
- Consistent spacing

Cards should feel collectible.

---

# Loader

Purpose:

Create anticipation.

Contains only:

- Foxglove crest
- Progress indicator

No text.

No unnecessary graphics.

---

# Motion

Animation Philosophy:

Visitors should feel movement.

They should not notice movement.

Standard transitions:

0.3–0.4 seconds.

Hero fade:

2.8 seconds.

Motion should always feel:

- Smooth
- Intentional
- Restrained

Never playful.

---

# Photography

Photography should emphasize:

- Monterey
- Ocean
- Championship golf
- Whiskey
- Cigars
- Brotherhood
- Golden hour
- Premium craftsmanship

Avoid obvious stock photography whenever possible.

---

# Botanical Usage

Botanical artwork is a supporting brand element.

Never primary content.

Treat it like letterpress artwork on premium stationery.

---

# Icons

Use only official Foxglove iconography.

Gold.

Consistent sizing.

Minimal usage.

---

# White Space

Empty space is intentional.

Do not add elements simply because space exists.

Luxury is communicated through restraint.

---

# Visual Hierarchy

Every page should naturally guide the eye:

Hero

↓

Introduction

↓

Primary Content

↓

Supporting Content

↓

Footer

Each section should support—not compete with—the previous one.

---

# Future Pages

Every page should inherit:

- Header
- Footer
- Typography
- Color palette
- Motion
- Card styling
- Botanical treatment
- Iconography

The homepage is the benchmark.

---

# Final Rule

Every new feature should answer one question:

**Does this make The Foxglove feel more exclusive, more refined, or more memorable?**

If the answer is no, it doesn't belong.

---

# Foxglove Design Principle

A visitor should leave remembering how **The Foxglove felt**, not how many features it had.
