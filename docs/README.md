# Overview

The Foxglove Invitational is the permanent digital home of The Foxglove Invitational golf tournament.

The platform preserves the tournament's history while providing members and administrators with a modern, secure experience for tournament management, media, player information, and future growth.

Version 1.0 establishes the official production baseline of the project.

# Architecture

The Foxglove follows a static-first architecture powered by Supabase services.

Major components include:

- Public Website
- Member's Lounge
- Administrator Dashboard
- Supabase Backend
- GitHub Repository

# Version 1.0 Scope

Version 1.0 includes the complete website, Member's Lounge, and Administrator Dashboard.

The following items are intentionally outside the Version 1.0 scope:

- Live scoring
- Mobile companion application
- Push notifications

These features are planned for future releases.
