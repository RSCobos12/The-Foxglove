# The Foxglove
# Homepage Style Guide

**Version:** 1.0  
**Status:** Active  
**Last Updated:** July 5, 2026  
**Owner:** Scott Cobos  
**Project:** The Foxglove Invitational Website

---

# Purpose

This document establishes the visual and interaction standards for the homepage of The Foxglove. Every future page should inherit these principles to ensure a consistent, premium experience across the website.

---

# Brand Identity

The Foxglove represents:

- Prestige
- Tradition
- Brotherhood
- Competition
- Exclusivity
- Sophistication

The experience should feel like an invitation into a private golf society—not a commercial golf website.

---

# Design Philosophy

**Less, but better.**

Every visual element must earn its place.

If two design solutions accomplish the same goal, choose the quieter, more restrained one.

Luxury should never feel loud.

---

# Color System

## Navy

Primary canvas.

Used for backgrounds and structure.

---

## Gold

Reserved for emphasis.

Used for:

- Icons
- Dividers
- Borders
- Hover states
- Crest
- Seal

Never overused.

---

## Cream

Primary reading color.

Chosen over pure white to create warmth and reduce contrast.

---

# Typography

## Headlines

- Elegant serif
- Large scale
- Generous spacing
- Confident
- Centered unless intentionally aligned otherwise

---

## Body Copy

Readable before decorative.

Short paragraphs.

Comfortable line height.

Editorial presentation.

---

# Hero Section

Purpose:

Create atmosphere before information.

Current behavior:

- Loader displays crest only.
- Hero image appears immediately.
- Hero image remains for 2 seconds.
- Hero video fades in over 2.8 seconds.
- Video plays once.
- Hero image returns.
- Hero image remains for 15 seconds.
- Cycle repeats.

The hero should feel cinematic rather than promotional.

---

# Welcome Section

Purpose:

Introduce the spirit of The Foxglove.

Emotion before logistics.

Botanical artwork:

- Opacity: 0.08
- Decorative only
- Frames the body copy
- Never competes with typography

---

# Exploration Cards

Purpose:

Invite discovery.

Standards:

- Equal height
- Equal spacing
- Gold foxglove icon
- Minimal hover movement
- Elegant transitions
- Consistent image treatment

---

# Navigation

Centered around the crest.

Spacing should feel balanced.

Navigation should never dominate the hero.

Hover states should remain understated.

---

# Loader

Contains only:

- Foxglove crest
- Progress indicator

No text.

Purpose:

Create anticipation before entering the experience.

---

# Motion Standards

Default UI transitions:

0.3–0.4 seconds.

Hero fade:

2.8 seconds.

Animation philosophy:

Visitors should feel movement without consciously noticing it.

Motion should always feel:

- Smooth
- Premium
- Intentional
- Restrained

---

# Photography

Preferred subjects:

- Monterey coastline
- Championship golf
- Golden hour
- Ocean
- Whiskey
- Cigars
- Brotherhood

Avoid obvious stock photography.

Maintain consistent color grading across all imagery.

---

# Botanical Artwork

Supporting brand element only.

Used sparingly.

Inspired by luxury stationery.

Never used as wallpaper or primary content.

---

# Iconography

Only official Foxglove iconography.

Gold.

Consistent sizing.

Minimal usage.

---

# White Space

White space is intentional.

Never fill empty areas simply because they exist.

Restraint communicates luxury.

---

# Visual Hierarchy

Every page should naturally guide the eye:

Hero

↓

Introduction

↓

Primary Content

↓

Supporting Content

↓

Footer

No section should compete with the previous one.

---

# Future Pages

Every page should inherit:

- Header
- Footer
- Typography
- Color palette
- Motion
- Card styling
- Botanical treatment
- Iconography

The homepage serves as the design benchmark for the entire website.

---

# The Foxglove Design Standard

Every future design decision should answer one question:

**Does this make The Foxglove feel more exclusive, more refined, or more memorable?**

If the answer is no, it doesn't belong.

---

# Guiding Principle

> **A visitor should leave remembering how The Foxglove felt, not how many features it had.**
